# FORMUP demo script (under 3 minutes)

1. Start the app with `npm run dev` and open the Vite URL.
2. On the welcome screen, select **Start a workout**.
3. Select **Lower body foundation**, then continue to camera setup.
4. Select **Preview demo mode**. Say clearly: “This is deterministic demo data; camera tracking is not active in this path.”
5. Let the sample counter run for a few seconds. Point out the rep count, demo label, and session timer.
6. Select **Finish session**, then **See your progress** to show the completion and local progress screens.
7. If camera access is available, restart and choose **Connect camera**. Show the landmark overlay and live form status. Do not promise a rep count unless a full squat cycle is visibly completed.

The demo proves the navigation flow, visual design, and the separated deterministic demo path. It does not prove Fire TV packaging, cloud services, persistent user accounts, or AI analysis.

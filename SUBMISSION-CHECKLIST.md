# Submission checklist

- [ ] Make the repository public or otherwise confirm the judges can access it.
- [x] Confirm `npm run build` completes locally.
- [ ] Run the app on the intended presentation device/browser.
- [ ] Capture screenshots or a short video of the complete navigation flow.
- [ ] If presenting live camera mode, grant camera permission and verify the model assets load before recording.
- [x] Keep demo mode clearly labelled as simulated sample data.
- [x] Do not add API keys, access tokens, or credentials to the repository.
- [ ] Verify the hackathon form includes the actual repository URL and demo URL/video.
- [ ] Confirm Fire TV packaging and remote-control requirements with the final submission rules.
- [ ] Describe the current MediaPipe implementation honestly; do not claim AWS or cloud functionality that is not present.
